# Ski Day 2.0 source

`index.html` is built from these three files: `shell.html` (markup and styles), `app.js` (the page) and
`mapdata.json` (line map geometry). The page reads one file, `data/dashboard.json`, which the logger writes
every run. Build: put `mapdata.json` and `app.js` into the two placeholders in `shell.html`.
